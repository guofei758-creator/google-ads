## 广告结构

以下用于整理和登记设置，不代表账户已经采用该结构。

| 层级 | 登记内容 | 对应检查 |
| --- | --- | --- |
| 账户 | 市场、币种、时区、购买转化动作 | EU / AU 数据口径是否清楚 |
| 广告系列 | 类型、预算、出价策略、目标、地域、语言 | 每个系列承担什么任务 |
| Search 广告组 | 型号、关键词、匹配方式、广告、落地页 | 搜索意图、文案与页面是否一致 |
| PMax 素材组 | 产品范围、素材、受众信号、搜索主题、落地页 | 是否混入不相关型号或品类 |
| 共享 / 账号级素材 | 站内链接、促销、图片等及其关联范围 | 旧价格或打印机素材是否出现在扫描仪广告中 |

记录账户与系列时，先明确市场、币种、时区、转化目标，再讨论结构是否需要调整。EU 与 AU 分开复盘。

## PMax 与 Search 常用规则

以下平台规则于 2026-11-12 核对 Google 官方文档；操作入口以实际账户界面为准。

### 1 受众信号

PMax 受众信号用于向系统提示潜在客户特征；系统仍可能触达信号以外、预测有较高转化可能的用户。自定义细分、网站访客或客户数据需关联到相应素材组的受众信号中。[官方说明](https://support.google.com/google-ads/answer/14530785?hl=en)

### 2 搜索主题

每个 PMax 素材组最多可添加 50 个搜索主题。主题用于补充系统从素材、Feed 和落地页获得的信息，不能据此把 PMax 的实际查询范围理解为仅限所填词语。[官方说明](https://support.google.com/google-ads/answer/14767319?hl=en)

### 3 其他品牌搜索词

PMax 出现其他品牌词，单凭品牌名称无法判定流量质量。整理时分别记录该类词的花费、购买转化、转化价值和实际 ROAS，再判断是否保留。

平台提供系列级否定关键词、账号级否定关键词及系列级品牌排除。品牌排除可作用于 Search 和 Shopping；带商品 Feed 的零售广告主可选择仅对 Search 文字广告排除品牌、保留对应 Shopping 流量。使用前记录作用范围。[官方说明](https://support.google.com/google-ads/answer/14587068?hl=en)

**操作方法**：将实际竞品词按“有购买价值”“明显无关”“数据不足”登记，再决定排除范围。单凭出现竞品名称，无法判断受众是否不准确。

### 4 最终到达网址扩展

开启最终到达网址扩展时，Google 可能根据查询改用更相关的站内落地页，并生成相应文字素材。核查型号错配时，应同时查看该设置、实际落地页和排除网址。[官方说明](https://support.google.com/google-ads/answer/17091269?hl=en)

### 5 Search 质量得分

质量得分是 Search 关键词层面的诊断工具，参考预期点击率、广告相关性和落地页体验。报表中的质量得分本身不作为竞价输入。整理优化结果时，同时保留购买转化、价值和花费数据。[官方说明](https://support.google.com/google-ads/answer/6167118?hl=en)

## 广告文案与图片

### 英文文字规格

| 类型 | 单条字符上限 | 单个广告 / 素材组数量上限 |
| --- | ---: | ---: |
| Search RSA 标题 | 30 | 15 |
| Search RSA 描述 | 90 | 4 |
| PMax 短标题 | 30 | 15 |
| PMax 长标题 | 90 | 5 |
| PMax 描述 | 90 | 5 |

来源：[Search RSA 规格](https://support.google.com/google-ads/answer/17092074?hl=en-GB)；[PMax 规格](https://support.google.com/google-ads/answer/17091269?hl=en)。

已确认的写作偏好是部分短标题约 20 个英文字符；这是文案长度偏好。PMax 官方规格另建议至少提供一条不超过 15 个字符的短标题。

### 文案要求

- 保留 Creality、3D Scanner 及具体型号等核心信息，避免全部写成泛促销句。
- 型号、适用场景、已核实参数、促销、服务分别承担不同信息作用。
- 每条标题能独立理解，也能与其他标题组合。
- 产品参数来自对应产品页、说明书或已核实产品资料；注明精度等参数的适用条件。
- 按具体需求决定是否展示价格、折扣额；此前部分 P1 文案要求只强调优惠，不直接写价格或优惠金额。
- 优惠码说明可采用“在结账时输入代码”的表达；每条投放前核对字符数和适用条件。
- 黑五文案保持简洁，截止时间与实际活动一致。

### 图片要求

PMax 官方推荐横图 1200 × 628、方图 1200 × 1200；各比例独立制作和检查。[图片规格](https://support.google.com/google-ads/answer/17091269?hl=en)

- 产品外观、型号、随附附件应与所售配置一致。
- 画面保持简洁，避免把无法核实的参数、过期价格或失效优惠写入素材。
- 配送、退货、保修与经销身份等信息，使用时对照对应站点的实际政策。
- 促销素材应记录适用产品、市场、期限与关联位置，方便到期替换。

## 数据复盘

### 比较口径

- EU 与 AU 分开；同一账户、币种、时区、转化口径和相同长度的完整周期进行比较。
- 购买、加购、注册分别记录；先核实转化动作，再解释转化次数与转化价值。
- 报表转化次数不直接等同于独立订单数；缺失或不完整数据单独注明。
- 全账户长期表现与单个系列某一时间段的表现分别记录。
- 更改后记录观察窗口和转化回补；结论同时参考花费、购买转化及购买价值。

### 复盘记录字段

| 类别 | 字段 |
| --- | --- |
| 基础信息 | 市场、账户、币种、时区、日期范围、数据完整性 |
| 系列设置 | 系列名、类型、状态、预算、出价策略、目标 ROAS / CPA |
| 效果指标 | 花费、展示、点击、CPC、CTR、购买转化、购买价值、CPA、实际 ROAS |
| 流量明细 | 搜索词、品牌 / 竞品分类、国家、设备、落地页 |
| 商品与素材 | 型号 / SKU、素材组、关联素材、Feed 状态、现用价格及优惠 |
| 更改记录 | 日期、修改前后设置、原因、观察窗口、后续结果 |

公式：实际 ROAS = 转化价值 ÷ 花费；CTR = 点击 ÷ 展示；每次购买成本 = 花费 ÷ 购买转化次数。比率按其对应转化动作和报表口径计算。

复盘优先使用最近完整 7 天、28 天及可比促销期；保留转化回补和活动变化记录。未填写的字段保留为空，不将缺失数据填为 0。

### 搜索词复盘

| 情况 | 应记录的证据 | 下一步 |
| --- | --- | --- |
| 出现竞品品牌词 | 花费、购买转化、购买价值、实际 ROAS | 按结果评估是否保留，核对排除范围 |
| 明显偏离所售商品的词 | 查询含义、实际落地页、关联素材与商品 | 检查相关性及可用排除方式 |
| 数据不足 | 累计花费、完整观察周期、转化回补 | 保留“数据不足”标记，避免提前定论 |

## GMC 与 Feed 检查

以下为检查清单，具体审核结论与商品资格以当前 Merchant Center 后台为准。

| 检查项 | 需要核对的内容 |
| --- | --- |
| 账户与商品资格 | 当前账号诊断、商品获批状态、问题发生时间及处理记录 |
| 商品与页面一致性 | 型号、变体、价格、币种、库存与落地页对应关系 |
| 优惠信息 | 适用品类、门槛、有效期、结账价及是否可以叠加 |
| 语言与市场 | Feed 语言、目标地区、页面语言和实际配送范围 |
| 站点信息 | 经营身份、联系方式、配送、退货与保修条款 |
| 更改记录 | 修改内容、提交日期、复核结果及后续表现 |

账户恢复、申诉或商品审核属于带日期的状态记录，不能用过去的状态推断当前状态。

#### 技术核对与证据边界

- **GTM 表单与链接触发**：Google 官方提醒，其他 JavaScript 可能干扰触发，应在预览模式验证。不能把按钮点击直接等同于企业成功收到表单。[GTM 官方说明](https://support.google.com/tagmanager/answer/7679102?hl=en)
- **SPA 页面测量**：Google 官方给出按历史变化或自定义事件测量虚拟页面的方法，并建议检查页面位置及来源参数；这说明 SPA 可以正确测量。页面浏览测量通过，也不代表所有表单、电话与业务线索都已经验收。[GA4 官方说明](https://developers.google.com/analytics/devguides/collection/ga4/single-page-applications)
- **速度评分**：评论中的“32 分”没有明确页面、设备和测试条件，不能当成案例已证实的统一结果。PSI 的实验室数据与真实用户数据含义不同，应结合实际移动端体验，而不是按建站平台排名。[PageSpeed 官方说明](https://developers.google.com/speed/docs/insights/v5/about)

#### 不宜直接沉淀为结论的评论

| 评论说法 | 处理方式 |
| --- | --- |
| “越来越多人使用 ChatGPT，所以 Google Ads 线索下降” | 仅作为外部变化假设。评论举出的是其他账户的个案，没有证明本案例的流量或需求因此下降 |
| “最近 B2B 都很难”或某个账户增长很好 | 都是有限样本，且本案例是家居服务；不能替代本账户按市场、设备和时段的证据 |
| “Lovable 一定快 / 一定比 Wix 慢” | 不按平台作统一判断；比较具体页面、设备、网络与实际用户表现 |
| “AI 生成的页面一定不可信” | 保留对图片错误、缺乏独特信息或不可核验内容的检查，不把制作工具本身当成原因 |
| “免费报价一定胜过免费咨询”或“黑五没有用” | 作为待测试假设，适用性取决于搜索意图、实际服务、优惠条件和后续流程 |

#### 建议排查顺序

1. **对账与功能**：核对真实收到的表单、来电、有效线索与报表，并用手机走完联系流程；先区分业务实际下降与漏报。
2. **流量与时间**：区分改版前已出现的下降，按市场、设备、搜索词与服务意图定位集中变化。
3. **页面验证**：检查首屏联系入口、可信证据、优惠及下一步是否清楚，先用少量可比流量测试。
4. **评价结果**：同时观察有效线索成本与成交，避免只追求表单数量、点击率或速度分数。

**对 Creality 电商的可复用知识**：把核心结果换成真实购买及成交价值，检查从商品页到结账的路径，并用准确型号图、可核验评价、清楚价格、配送与售后信息支持购买判断；家装服务的“预约咨询”按钮不能直接套用为电商最优 CTA。

**当前结论**：这个帖子支持一套排查和测试方法，尚不能确定导致下降的具体因素；现有截图未提供修复后的效果数据。
